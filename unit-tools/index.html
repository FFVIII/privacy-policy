Unit Tools — Privacy Policy

Last updated: August 24, 2026

Data Collection

Unit Tools does not collect, store, or transmit any personal data. Your unit preferences and app settings are stored locally on your device only. No account or sign-in is required.

Currency Exchange Rates

When you use the Currency category, the app fetches live exchange rate data from open.er-api.com. This request contains no personal information — it is a simple public API call that returns exchange rate numbers. No user data is sent to this service.

Third-Party Services

The only external service this app contacts is open.er-api.com, used solely to retrieve currency exchange rates. This app does not use any analytics, advertising, or crash-reporting services.

Permissions

This app does not request access to your camera, microphone, location, contacts, or photos.

Contact

If you have any questions, please contact: fangvsyu@gmail.com

Unit Tools — 隐私政策

最后更新：2026年8月24日

数据收集

Unit Tools 不收集、存储或传输任何个人数据。您的单位偏好和应用设置均仅存储在您的设备本地，无需注册或登录账号。

货币汇率

当您使用货币换算功能时，应用会从 open.er-api.com 获取实时汇率数据。该请求不包含任何个人信息，仅为获取汇率数字的公开 API 调用，不会向该服务传送任何用户数据。

第三方服务

本应用唯一访问的外部服务为 open.er-api.com，仅用于获取货币汇率。本应用不使用任何分析、广告或崩溃统计服务。

权限

本应用不会请求访问您的相机、麦克风、位置、通讯录或照片。

联系方式

如有任何疑问，请联系：fangvsyu@gmail.com
